## The letter: A — coffee

Coffee wins because it is the louder drink: it wakes you up, it bites back, and it turns a sleepy morning into a decision — tea soothes, coffee declares.

## How it works

`main.py` (Python standard library only) writes exactly one character, `A`, to `/output/entry.txt` — nothing else, no word, no explanation, no punctuation. It asserts the gate twice: before writing (exactly one character, non-whitespace, `A` or `B`) and after writing, by reading the file back and confirming it holds exactly `A` as a single byte.

Run it with:

```sh
python3 main.py
```
